## Local LLM Experiment

As part of my Agentic AI learning, I experimented with running a
small language model locally using Ollama and OpenWebUI.

### Stack
- Ollama
- OpenWebUI
- SmolLM 135M
- Local inference

### Result

Successfully ran SmolLM 135M locally and interacted with it through
OpenWebUI without relying on a cloud-hosted LLM API.
